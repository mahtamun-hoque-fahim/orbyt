## Auth Levels Defined

| Level         | Implementation                                                                                 |
|---------------|-----------------------------------------------------------------------------------------------|
| public        | No session check. Redirect to /dashboard if already authenticated (login/signup only).        |
| authenticated | middleware.ts checks session via Better Auth. Redirect to /login if no valid session.         |

Public routes exempt from middleware: `/`, `/login`, `/signup`, and Next.js internals (`/_next`, `/api/auth`).

## Notes

- `/onboarding` must redirect to `/dashboard` if the user already has user_phases rows — prevents re-onboarding on revisit.
- `/phase/[slug]` resolves slug against `user_phases` filtered by both `slug` AND `user_id`. A 404 response if slug belongs to a different user.
- `/settings` opens on the Notifications tab by default (most frequently used). Tab state can live in a URL search param `?tab=notifications|profile|track`.
- No admin routes in v1. The seed data is committed via a script, not a UI.
